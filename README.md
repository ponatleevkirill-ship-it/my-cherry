# CHERRY — сайт редакции

## Структура проекта
- `index.html` — страница сайта (HTML, CSS и JavaScript).
- `images/templates/` — фотографии для шаблонов публикаций.

## Изображения шаблонов
Пути к изображениям указаны в `index.html` и начинаются с `images/templates/`.
Если добавляете новую фотографию, загрузите её в эту папку и укажите относительный путь в объекте изображений в `index.html`.

## Публикация через GitHub Pages
В репозитории откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем сохраните.
